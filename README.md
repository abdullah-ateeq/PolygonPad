# PolygonPad

PolygonPad is a modern Android calculator and utility application built using Kotlin and Jetpack Compose. It features a beautiful, adaptive UI using Material 3 design guidelines and provides calculation history, customizable settings, and dynamic theming.

## Features

- **Advanced Calculator:** Perform a variety of mathematical operations with an intuitive, clean interface.
- **Calculation History:** Keeps track of your past calculations so you can review or reuse them.
- **Customizable Settings:** Easily configure the app's behavior and aesthetics.
- **Material 3 Design:** Built with Jetpack Compose, featuring dynamic colors and edge-to-edge support for a highly polished, modern look.
- **Dark/Light Theme:** Full support for system dark mode and custom app themes.
- **Splash Screen:** Seamless entry experience.

## Tech Stack

- **Language:** Kotlin
- **UI Toolkit:** Jetpack Compose & Material 3
- **Architecture:** MVVM (Model-View-ViewModel)
- **Navigation:** Jetpack Navigation Compose
- **Local Storage:** DataStore Preferences
- **Concurrency:** Kotlin Coroutines & Flow

## Requirements

- Android Studio Koala or newer
- Minimum SDK: API 24 (Android 7.0)
- Target SDK: API 37

## Building the Project

1. Clone this repository:
   ```bash
   git clone https://github.com/abdullah-ateeq/PolygonPad.git
   ```
2. Open the project in Android Studio.
3. Sync the project with Gradle files.
4. Run the app on an emulator or a physical device.
